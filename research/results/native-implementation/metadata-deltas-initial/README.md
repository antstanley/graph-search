# Preliminary metadata delta measurement

This capture predates incremental corpus-length totals. It measures posting reuse
with recomputed corpus averages and is retained as preliminary evidence only.
The final `metadata-deltas` capture supersedes it for the completed implementation.

The final probe also preserves function names in edited signatures and moved
symbol IDs. Consequently the preliminary and final timings are not an isolated
comparison of the corpus-total optimization.
